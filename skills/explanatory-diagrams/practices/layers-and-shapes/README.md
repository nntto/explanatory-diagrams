# 形・線・置き場所に、意味を 1 つずつ持たせる

1 枚の図の中で、同じ形・同じ線・同じ置き場所が、いつも同じ意味を表すようにする。逆に、同じ種類のものは同じ形で、同じ関係は同じ線で描く。決まりがそろっていれば、読み手は 1 度覚えるだけで図全体を読める。

- 形：たとえば、角ばった箱は文書やデータ、角の丸い太枠は作業をするもの、と決めたら、ほかの意味には使わない。並ぶもの（兄弟）は形と大きさを、入れ子（親子）は囲み方をそろえる。
- 線：1 種類の線に 1 つの関係を持たせる。たとえば、実線は「読む・渡す」、太い両向きは「使う」。
- 置き場所：まとまりや境界に意味があるなら、見て分かるようにする。帯で囲む、列をそろえるなどの方法があり、どれを使うかは図による。

決めた意味は、図の下に「図の読み方」としてまとめる。

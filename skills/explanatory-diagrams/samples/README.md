# サンプルの一覧

18 枚のサンプルと、それぞれが示している表現を並べる。サンプルは、当てはまるものを選んで使う型ではなく、こういう表現もできると示す例。この一覧は、エージェントと人の両方が読む。エージェントは [SKILL.md](../SKILL.md) からこの一覧をたどり、図に取り入れられる表現を探す。

サンプルの題材、人名、数値、業務のルール（返金を自動で承認する金額、送料など）は、すべてサンプルのために作った架空のもの。

## サンプルの分け方

サンプルは 3 種類ある。

- **見せ方**：変更前後の比べ方など、どの図にも組み合わせられる体裁。
- **リファクタリングの説明**：見せ方を、よくあるリファクタリングに当てはめた例。
- **図の種類**：構成図、シーケンス図、状態遷移図など、記法や題材ごとのサンプル。変更前後にはしていない。

たとえば AWS の構成の変更を説明するときは、「AWS 構成図」の記法で描き、「1 枚に差分を重ねる」の見せ方で変更点を示す。

図形で描いたサンプルは、同じ架空の EC サービス（注文・支払い・出荷）を題材にしている。デザインの変化とパレットのサンプルは、サンプルのために AntD で作った架空の雑貨店の管理画面のテーマを題材にしている。画面の画像はその画面を撮ったもので、画面のソースはこのリポジトリ（nntto/explanatory-diagrams）の [`tests/skill-evals/explanatory-diagrams/sources/mock-admin-ui/`](https://github.com/nntto/explanatory-diagrams/tree/main/tests/skill-evals/explanatory-diagrams/sources/mock-admin-ui) にある。パレットの変更前の値は、AntD が計算した値を載せている。

サンプルはすべて `.drawio.svg` で、draw.io で開くとそのまま編集できる。使う色と線・記号の描き方は [references/drawio-style.md](../references/drawio-style.md) にまとめている。

## 見せ方

### 左右に並べて比べる

例：構造の違いそのものを見せたい変更。変更前と変更後で同じ枠組み（この例では層の帯）を共有し、変わったところだけが目に入るようにする。「3 つ → 1 つ」のような数の変化も添える。

![画面が外部 API を直接呼ぶ構造から、サービス層を通す構造への変更を左右に並べた図](before-after-split/before-after-split.drawio.svg)

### 1 枚に差分を重ねる

例：全体の中の一部だけが変わる変更。変更後の図に、足したものと消したものを重ねる。このサンプルでは、足したものを青の枠、消したものを灰の破線と ✕ で示している。

![メール送信を SQS 経由にする変更を、AWS 構成図に重ねた図](before-after-diff/before-after-diff.drawio.svg)

### 画面を並べてデザインの変化を比べる

例：色、余白、角丸など、見た目が変わる変更。変更前後の実画面を左右に並べ（横に長い部品は上下に並べ）、見てほしい部品を枠で囲む。枠に番号を付け、変わった値の表と対応づける。このサンプルでは、枠を橙にしている。

![日付範囲の塗りとフォーカスの輪、link の色を店の色に揃える変更を、変更前後の画面で比べた図](design-before-after/design-before-after.drawio.svg)

### 色のパレットを前後で比べる

例：テーマの色の段階（背景・枠線・塗り・文字）をまとめて変える変更。段階を列にそろえ、変える色だけ変更前と変更後の行を上下に並べる。変えない色は 1 度だけ載せ、問題のある段階と変えた値を枠で囲む。このサンプルでは、問題のある段階を橙、変えた値を青の枠にしている。

![主色の 10 段階を自分で決め、灰色の段階をなくす変更を、色のパレットで比べた図](palette-before-after/palette-before-after.drawio.svg)

## リファクタリングの説明

### 状態の置き場を移す

例：フックやモジュールが持っていた状態を、別の場所へ切り出すリファクタリング。移す状態と移した先を示し、状態の数が変わらないことも添える。このサンプルでは、移す状態を橙、移した先を青で示している。

![useOrderEditor の状態を useDraft に切り出す変更を左右に並べた図](refactor-move-state/refactor-move-state.drawio.svg)

### 名前を揃える

例：名前だけを変えるリファクタリング。名前を部品ごとに分けて表に並べ、規則から外れた名前と新しい名前を示す。呼び出し側で変わるところも並べる。

![フックの名前を use＋対象＋操作 に揃える変更の図](refactor-rename/refactor-rename.drawio.svg)

### 関数を切り出して公開する

例：ファイルの中に閉じていた関数を切り出して公開するリファクタリング。今の利用関係は実線、後続の PR でつなぐ利用側は破線で示す。

![注文と表の変換を別ファイルに切り出して公開する変更を左右に並べた図](refactor-extract-module/refactor-extract-module.drawio.svg)

### 状態を共有する

例：部品ごとに持っていた状態を、同じデータを扱う部品のあいだで 1 つにまとめるリファクタリング。状態の数の違い（3 つ → 1 つ）で変化を示し、移す前の位置を破線で残す。

![表ごとの「保存中」を注文ごとに 1 つにまとめる変更を左右に並べた図](refactor-share-state/refactor-share-state.drawio.svg)

### コピーして持ち回っていた値を削除する

例：いくつかの段階にまたがる処理で、コピーして持ち回っていた値を削除し、どの処理も元の値を読むようにするリファクタリング。データ・読む処理・結果を帯に分け、変更前と変更後を 1 枚に重ねる。このサンプルでは、削除したものを橙の破線と打ち消し線、新しく読む値とそれによって変わる値を青で示している。

![商品データの取り込みバッチで、持ち回っていた display_name を削除し、どの処理も name を読むようにする変更の図](refactor-remove-duplicate/refactor-remove-duplicate.drawio.svg)

## 図の種類

### AWS 構成図

例：サービスの配置と冗長化を説明する。AWS のアイコンとグループ（リージョン・VPC・AZ・サブネット）を使い、リクエストの流れに番号を振る。

![注文 API を 2 つの AZ に置いた AWS 構成図](aws-architecture/aws-architecture.drawio.svg)

### シーケンス図

例：複数の参加者のあいだのやり取りを、順序どおりに説明する。同期・非同期・応答の矢印、活性区間、alt の枠を使い分ける。

![注文の確定から決済の完了までのシーケンス図](sequence/sequence.drawio.svg)

### 状態遷移図

例：状態と、状態を移すイベント・条件・処理を説明する。遷移のラベルは「イベント [条件] / 処理」の順に書く。

![注文ステータスの状態遷移図](state-machine/state-machine.drawio.svg)

### C4 コンテナ図

例：システムを構成するアプリ・DB・外部サービスと、そのあいだの関係を説明する。関係線には「何をするか」と「[技術]」を書く。

![注文システムの C4 コンテナ図](c4-container/c4-container.drawio.svg)

### ER 図

例：テーブル・列・キーと、テーブル間の行数の関係を説明する。カラス足記法の記号の意味を凡例に示し、設計上の判断は注記で残す。

![注文・明細・支払いなどのテーブルの ER 図](er-diagram/er-diagram.drawio.svg)

### 業務フロー（BPMN）

例：担当ごとの作業と分岐を説明する。レーンで担当を分け、人の作業とシステムの処理をマークで区別する。

![返品から返金までの業務フロー](business-flow/business-flow.drawio.svg)

### オイラー図（集合と要素）

例：条件の組み合わせで決まる対象を説明する。集合を円、要素を点で置き、要素ごとの判定表を添える。

![メールの送り先を決める条件のオイラー図](euler-sets/euler-sets.drawio.svg)

### コンポーネントと状態

例：画面の状態をどこが持ち、誰が読み書きするかを説明する。状態の種類は枠線（実線・破線・点線）で区別する。

![注文編集画面のコンポーネントツリーと状態の置き場](state-ownership/state-ownership.drawio.svg)

### コードと実行時の値

例：入力によって、実行される行や返る値が変わる処理を説明する。コードの各行と、入力ごとに評価した値を同じ高さに並べる。

![送料を計算する関数と、3 つの入力で評価した値](code-trace/code-trace.drawio.svg)

## サンプルの追加

1. 業務固有の名前、PR 番号、チケット番号を一般的な名前に置き換えた図を用意する。
2. [references/drawio-workflow.md](../references/drawio-workflow.md) の手順で `.drawio.svg` を書き出し、`samples/<pattern>/` に置く。
3. この README の「見せ方」「リファクタリングの説明」「図の種類」のうち当てはまる節に、そのサンプルが示す表現と画像を追加する。
